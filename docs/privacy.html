Политика конфиденциальности

Приложение «Расписание СПбГМТУ» и его веб-версия · редакция от 25 сентября 2026 года

Приложение не собирает персональные данные. В нём нет регистрации, аккаунтов, аналитики, рекламы и сторонних SDK. Разработчик не получает о пользователе никаких сведений — ни прямо, ни косвенно.

Какие данные обрабатываются на устройстве

  • Выбранная учебная группа — её номер хранится в приватном хранилище приложения, чтобы не выбирать группу заново при каждом запуске.
  • Кэш расписания — разобранное расписание группы и нескольких последних открытых преподавателей в приватной папке приложения, чтобы оно работало без интернета.
  • Планы корпусов — файлы поэтажных планов, если вы их открывали.
  • Служебные отметки — когда последний раз проверялась новая версия и сколько раз о ней напомнили, когда виджет последний раз обновлял расписание.

Эти данные не покидают устройство. Все вместе они удаляются вместе с приложением или через «Очистить данные» в настройках Android; сохранённое расписание — ещё и командой «Очистить кэш и загрузить заново» в меню.

Куда приложение выходит в сеть

  • www.smtu.ru — официальный сайт университета: страницы расписания при запуске, по кнопке обновления и для виджетов, если сохранённому расписанию больше 12 часов.
  • isu.smtu.ru — сервер университета с поэтажными планами корпусов: только когда вы открываете план, и только один раз на корпус.
  • cryptoteep.github.io — страница этого проекта на GitHub Pages. Оттуда берётся резервная копия того же расписания (когда сайт университета недоступен, например под VPN) и раз в сутки — номер последней версии приложения.

Запросы не содержат сведений о пользователе, кроме неизбежных технических данных обычного HTTP-запроса (IP-адрес и строка браузера). Их обрабатывают сами эти сайты по своим правилам: университет — по своим, GitHub — по своему положению о конфиденциальности. Собственных серверов у проекта нет, и разработчику эти запросы не видны.

Веб-версия

Веб-версия работает в браузере и открывается с той же страницы на GitHub Pages; на сайт университета она не ходит. Выбранная группа и сохранённое расписание лежат в хранилище браузера (localStorage) на вашем устройстве и никуда не отправляются. Стереть их можно, очистив данные сайта в настройках браузера.

Разрешения

Приложение запрашивает одно разрешение — доступ в интернет. Оно не обращается к контактам, файлам, камере, микрофону, геолокации, SMS и звонкам.

Резервное копирование

Если в системе включено резервное копирование Android, данные приложения (выбранная группа, кэш и служебные отметки) могут копироваться в облако владельца устройства средствами самой системы. Разработчик к этим копиям доступа не имеет.

Дети

Приложение не предназначено для сбора данных о ком-либо, включая несовершеннолетних, и не содержит материалов возрастного ограничения.
