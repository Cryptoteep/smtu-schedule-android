# История изменений

Формат основан на [Keep a Changelog](https://keepachangelog.com/ru/1.1.0/).

## [2.0] — 05.09.2026

Переписаны разбор страниц, расчёт чётности недель и интерфейс. Приложение
по-прежнему без единой сторонней библиотеки; release-APK — 53 КБ.

### Исправлено

- **Расписание преподавателя показывалось без групп.** Парсер читал карточный
  вид сайта — единственный, где у занятия не указана группа. Теперь читается
  табличный вид, а карточный остался запасным вариантом.
- **Чётность недели уезжала.** Она считалась от захардкоженной опорной недели,
  а калибровка по строке «Сегодня: … верхняя неделя» не работала — такой строки
  на страницах нет. Теперь цикл верхняя/нижняя восстанавливается из точных дат
  самих занятий и не устаревает к следующему семестру.
- Чётность считалась неверно для дат раньше опорной точки (усечение вместо
  `floorMod`), а сама опорная точка не выравнивалась на понедельник — из-за
  этого чётность могла меняться в середине недели.
- Преподаватель терялся, если сайт печатал его без ссылки на карточку персоны;
  примечание вида «С 26.10 по 14.12» попадало в поле преподавателя.
- Загрузка не проверяла код ответа сервера: страница-ошибка молча становилась
  «пустым расписанием».

### Добавлено

- Просмотр по дням с полосой Пн–Вс и количеством пар, свайпы влево/вправо,
  кнопка «Сегодня».
- Подсветка идущей сейчас пары; прошедшие сегодня — приглушены.
- Расписание преподавателя открывается прямо в приложении, со всеми его
  группами; из него можно перейти к расписанию любой из групп.
- Поиск по предмету, преподавателю, аудитории, типу занятия и группе.
- Добавление пары в календарь телефона и отправка дня или недели текстом.
- Тёмная тема — автоматически по системной.
- Иконка приложения, включая адаптивную и монохромную (темы Android 13+).
- Понятные пустые состояния: свободный день подсказывает, когда следующие
  занятия; неделя вне семестра говорит, за какой период расписание есть.
- Пункт меню «Очистить кэш и загрузить заново».

### Изменено

- Ядро (даты, HTML, модель, парсер, чётность, запросы) отделено от Android —
  и покрыто 50 JUnit-тестами, которые гоняются на реальных страницах smtu.ru.
- Сеть: проверка кода ответа, gzip, повтор при сбое, ограничение размера
  ответа; запись кэша атомарная и версионированная, кэш преподавателей
  подрезается.
- Даты считаются в epoch-днях, названия дней и месяцев зашиты по-русски —
  приложение работает одинаково на телефоне с любой локалью и часовым поясом.
- Release подписывается настоящим ключом (схемы v1+v2+v3), сборка проходит
  R8 и сжатие ресурсов; lint чистый.
- Gradle-обёртка в репозитории, сборка и тесты в GitHub Actions.

## [1.0] — 08.2026

занятия, расписание преподавателя списком.
