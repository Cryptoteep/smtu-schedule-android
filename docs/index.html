Как установить

  1. Скачайте файл на телефон Кнопка выше. Браузер спросит, сохранять ли файл — сохраните.
  2. Откройте скачанный файл Из шторки уведомлений или из папки «Загрузки».
  3. Разрешите установку из этого источника Android один раз спросит разрешение для браузера — это стандартный шаг для любого приложения не из Play Маркета.
  4. Выберите свою группу Список всех 449 групп с поиском. Дальше группа запомнится.

Почему телефон показывает предупреждения

Android показывает эти окна любому приложению, установленному не из Play Маркета, независимо от того, что внутри. Это предупреждение о способе установки, а не о находке вируса.

«Этот тип файла может нанести вред устройству» — стандартный текст браузера для всех APK.
«Play Защита не проверяла это приложение» — значит только то, что его нет в каталоге Google.

Проверить, что вам подсунули именно то приложение, можно без доверия к автору: исходный код открыт целиком, а файл собирается из него автоматически на серверах GitHub — сборку и её лог видно всем.

Вопросы

Расписание не загружается

Сервер университета не пускает часть зарубежных адресов: под VPN с иностранным выходом первая загрузка может не пройти. Выключите VPN и нажмите ⟳ — дальше приложение работает даже без сети.

На сайте расписание поменялось, а в приложении старое

Кнопка ⟳ в шапке. Если университет переписал страницу целиком — меню ⋮ → «Очистить кэш и загрузить заново».

А для iPhone?

Готовится веб-версия, которая открывается по ссылке и добавляется на экран «Домой» как обычное приложение — без App Store и без установки.

Приложение официальное?

Нет. Это студенческий проект: он просто показывает то, что университет публикует на своём сайте. Все данные расписания принадлежат СПбГМТУ.
