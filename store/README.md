## RuStore — главный канал для России

Бесплатно, физлицу можно, модерация обычно 1–3 рабочих дня. После публикации
люди ставят приложение из магазина: ни «неизвестного источника», ни ругани
Play Защиты, плюс автообновления.

1. <https://console.rustore.ru> → войти через Госуслуги (нужна подтверждённая
   учётная запись — это единственный шаг, который нельзя сделать за вас).
2. «Стать разработчиком» → тип «Физическое лицо» → принять оферту.
   Регистрация бесплатная, взносов нет.
3. «Создать приложение» → загрузить APK → заполнить карточку текстами из
   [`listing.md`](listing.md), приложить иконку и скриншоты.
4. В разделе про данные указать: приложение **не собирает** персональные данные;
   ссылка на политику конфиденциальности — из таблицы выше.
5. Отправить на модерацию.

Замечание про монетизацию: с 01.02.2026 платные приложения и подписки доступны
только ИП и юрлицам. Нас это не касается — приложение бесплатное, физлицо
публикует и обновляет его без ограничений.

## IzzyOnDroid — каталог для F-Droid, без бюрократии

Бесплатно, без документов, добавляют вручную за несколько дней. Приложение
подходит по всем требованиям: открытый код, APK в релизах GitHub, 54 КБ
(лимит 30 МБ), ноль проприетарных зависимостей и трекеров.

Заявка — одна issue: <https://gitlab.com/IzzyOnDroid/repo/-/issues> с ссылкой
на репозиторий. Дальше каталог сам подхватывает каждый новый релиз с GitHub.
После этого приложение видно в F-Droid-клиентах (F-Droid, Neo Store, Droid-ify),
где установка тоже идёт «из магазина».

## Galaxy Store — для телефонов Samsung

Регистрация продавца бесплатна (Seller Portal, вход через Samsung account),
физлицу можно. Просят те же материалы; отдельно — баннер 512×512 и описание
на английском. Смысл: у СПбГМТУ много студентов с Samsung, а установка из
Galaxy Store не вызывает предупреждений.

## Google Play — если захочется

Единственный магазин, который снимает предупреждения Play Защиты полностью,
но регистрация стоит 25 $ разово и требует подтверждения личности. Учтите
заодно: с сентября 2026 Google вводит обязательную верификацию разработчиков
даже для приложений вне Play — бесплатный «любительский» тип аккаунта
позволяет раздавать сборку максимум на 20 устройств, так что для массовой
раздачи рано или поздно понадобится либо Play, либо магазины выше.

## Чего делать не нужно

- Загружать APK на файлообменники и в архивы вроде «apk-скачать» сайтов —
  именно оттуда берутся заражённые копии, и именно поэтому люди боятся APK.
- Пересобирать под каждый магазин: один и тот же подписанный файл подходит
  везде. Ключ подписи — один и тот же навсегда, иначе обновление не встанет
  поверх установленного приложения.
